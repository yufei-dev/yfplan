## ✅ v1.3.0 — 数据外部化

**为什么必须做**：九周计划、任务模板曾是 JS 字面量。不变成「可替换的数据」，
用户就无法导入自己的计划——这是所有多用户功能的前置条件。

- [x] `TMPL` / `WEEKS` / `TL` / 听力材料清单 → 结构化**计划数据 JSON**
      （页面内 `<script type="application/json" id="planData">`；代码只保留加载器
      `normalizePlanData()`，渲染逻辑零改动）
- [x] 定义**计划文件格式**并归档：[`docs/PLAN_FORMAT.md`](PLAN_FORMAT.md)
      （字段含义、类型表、4 周最小示例、`formatVersion` 约定）
- [x] 「导入文件」升级：自动识别计划文件 / 打卡文件；新增「↺ 恢复默认计划」按钮
- [x] **保持向后兼容**：打卡记录 `{updated, items}` 格式不变

**验收结果（2026-10-16，自动化测试）**：
- 基线：内置计划经外部化加载后 9 周 / 61 天 / 零报错，与原版逐字段一致
- **4 周测试计划：导航 4 周按钮、课表正常渲染、「共 27 天」自动适配 ✔**
- 打卡兼容：勾选 → 刷新 → 状态完整保留，0 报错

**注意**：`SAVE_FILE` 的文件名不能跟着改，见 CHANGELOG v1.2.0 的说明。
