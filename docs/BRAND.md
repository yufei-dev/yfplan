# 品牌规范（于飞计划）

> **本文是后续所有版本必须遵循的准则。**
> 来源：品牌文案库（2026-10-15 由项目所有者确立），已归档于此。
> 修改代码中的任何用户可见文案前，先查本文。

---

## 一、品牌名称（强制统一）

| 用途 | 名称 |
|---|---|
| **中文主名称** | **于飞计划** |
| **英文主名称** | **YUFEI PLAN** |
| 小尺寸图标 / favicon / 侧边栏 | **YP** 或独立的**羽翼符号** |

**规则**：
- 正式场合（Logo、浏览器标签、登录页、页眉）**统一使用「于飞计划」**
- 不要在不同页面随意更换英文名，保持品牌一致性

## 二、标语（分工明确，不要混用）

| 类型 | 内容 | 使用场合 |
|---|---|---|
| **主宣传语**（长期固定） | **以计划为翼，以坚持为路。** | 官网首屏、产品发布、品牌展示 |
| **品牌精神表达** | **凤凰于飞，终抵远方。** | 品牌故事、About 页面 |

> 两句分工：前者沟通产品价值，后者承载文化内涵。
> **不要把这两句当成普通标语随意替换。**

## 三、品牌关键词

**规划、成长、秩序、坚持、进步、远方**

## 四、产品定位

> 面向**多用户**的学习计划与目标管理平台，采用**极简、现代、具有科技感的 SaaS 风格**，
> 融入「凤凰于飞」的文化寓意。

**产品定位短句**：让计划有序，让成长可见。
**极简品牌签名**：让每一个目标都有路径，让每一份努力都不被辜负。

## 五、视觉方向

| 项目 | 规范 |
|---|---|
| **风格** | 极简科技风 · 克制的高级感 · 清晰的信息层级 |
| **字体** | 中文用清晰的现代黑体；英文用简洁的无衬线字体 |
| **色彩** | 黑 / 白 / 灰为基础 + **一种**低饱和强调色（深蓝、青绿或克制的暖金） |
| **图形** | 凤凰、羽翼、上升轨迹、路径等元素**抽象化**处理 |
| **布局** | 清晰层级、稳定间距、统一圆角与图标规范 |
| **交互** | 任务完成 / 进度增长 / 阶段达成要有明确但**不过度夸张**的反馈 |

**⚠️ 明确禁忌**：不要写实凤凰插画；避免大面积复杂纹理和难以辨认的艺术字。

## 六、页面文案参考

### 官网首页
- 主标题：**以计划为翼，以坚持为路。**
- 副标题：把模糊的目标变成清晰的计划，把每一天的行动沉淀为看得见的成长。
- 其他可用短句：
  - 让每一个目标，都有清晰的起点。
  - 计划不止于制定，更在于持续完成。
  - 记录每一次行动，看见每一点进步。

### 仪表盘 / 任务页
- 今天，也向目标靠近了一步。
- 从一个明确的目标开始。
- 今天的每一步，都算数。

### 学习与备考场景
- 把学习目标拆解成每天都能执行的任务。
- 不追求每一天都完美，只追求每一天都在前进。
- 今天学到的内容，会成为明天的底气。

### 激励与反馈
| 场景 | 文案 |
|---|---|
| 开始行动 | 万事从第一步开始。 / 先完成，再完善。 |
| 坚持执行 | 慢一点没关系，别停下来。 / 进步不一定显眼，但每一步都算数。 |
| 任务完成 | 做得很好，今天又完成了一项重要的事。 |
| 暂时落后 | 计划可以调整，方向不必轻易放弃。 |
| 阶段达成 | 这段努力，终于有了清晰的答案。 |
| 空白状态 | 这里还没有任务，创建一个今天的目标吧。 |
